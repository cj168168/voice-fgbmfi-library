# VOICE FGBMFI Digital Library

Digital bookshelf and flipbook for VOICE FGBMFI Indonesia.

## Cloudflare deployment

- Worker: `voice-fgbmfi-library`
- D1 binding: `DB`
- R2 binding: `BUCKET`
- Build command: `npm run build`
- Deploy command: `npm run deploy`
- Admin login: `/admin/login`

The public library includes VOICE Edisi 160. Additional PDF editions and cover images are managed through the protected admin panel.
